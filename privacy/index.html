Privacy Policy

Last updated November 23, 2026

This policy explains how the ClipForge ShortDesk desktop tool handles data and what happens when you visit this website.

YouTube authorization

When you connect YouTube, ShortDesk opens Google's OAuth consent flow and exchanges the returned authorization code with Google. It requests upload and read-only YouTube permissions to verify the channel and check uploads. It receives an access token, a refresh token, and expiration information, and checks the channel ID against the configured channel.

The access token authorizes YouTube API requests. ShortDesk uses the refresh token to obtain a new access token when the current one is close to expiry or authentication needs refreshing. It keeps these credentials, the channel ID and handle, and the OAuth client identifier in a local authorization file.

Instagram authorization

ShortDesk reads a Meta-issued access token from a local file chosen by the user or imports it into a managed local file. Importing leaves the original token file in place. ShortDesk uses the token to check the assigned Instagram account ID and username, permissions and eligibility, and to authorize requests to Meta. The Instagram adapter does not perform an OAuth code exchange or refresh this token. A replacement token must be provided when required.

Device storage and publication records

ShortDesk keeps its SQLite database in the local ShortDesk workspace on your device. It records file paths and fingerprints, queue times, titles, descriptions and hashtags, processing and retry status, and returned publication IDs and timestamps. The adapters can also retain upload checkpoints and identifiers such as YouTube video IDs and Instagram container and media IDs. Publication records support status checks and duplicate prevention.

Credentials are stored outside SQLite in local files. ShortDesk uses restricted file permissions for the credential files it manages. User-supplied credential files and any copies you make remain on your device at the locations you choose.

Information sent to platforms

For a real upload, ShortDesk sends the selected video and the metadata or settings needed by the destination to Google for YouTube or Meta for Instagram. It also sends authorization and account or publication identifiers to the appropriate platform to verify the account, create uploads, and check status. Google and Meta handle received data under their respective policies. This website does not receive ShortDesk credentials, queue records, or video files.

Retention, disconnection, and deletion

ShortDesk sets no fixed automatic expiry for its local credentials, queue records, publication history, or upload checkpoints. Those records can remain after authorization expires. Platform copies are subject to the platform's own retention and deletion practices.

To disconnect, stop real publishing for that platform and revoke the grant or disable the token through Google or Meta. With ShortDesk stopped, remove the relevant local credential files, any original imported copy you no longer need, and the related settings. Removing local credentials does not remove already uploaded posts.

To clear local queue and publication records, close ShortDesk and remove the relevant local ShortDesk workspace and any separate adapter upload records or exports you want to delete. Removing a workspace can also remove its local media copies and duplicate history. Manage posts already uploaded through the destination platform.

Website hosting and contact

This informational site has no account login, forms, analytics scripts, or embedded platform widgets. GitHub Pages logs visitor IP addresses for security under the GitHub Privacy Statement.

If you email kontentzavod0@gmail.com with a question or deletion request, we use your email address and message to respond and retain the correspondence as needed to handle the request. We can assist with identifying local data, but cannot erase files from your device or delete platform copies on your behalf. Please do not send tokens, passwords, or database files.

Planned TikTok integration

TikTok account authorization and Content Posting API uploads are planned. ShortDesk does not currently obtain TikTok OAuth tokens, store TikTok account or post identifiers from the TikTok API, or send media to TikTok. This policy will be updated before a TikTok integration is made available.
